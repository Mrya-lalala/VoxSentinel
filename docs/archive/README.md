# Historical archive

These documents preserve experiment evidence and earlier decisions. Their status statements, paths and instructions may describe a superseded stage. Use the [current documentation](../README.md) for setup and operation.

- `history/`: implementation reports, old handoffs, reviews, diagnostics and earlier evaluation results.
- `prompts/`: completed agent assignments, retained for provenance rather than reuse as current instructions.

No model artifacts, datasets or evaluation evidence were deleted during this documentation cleanup. Git history retains the original document locations.
